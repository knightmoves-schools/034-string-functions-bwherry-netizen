# 034 String Functions

[![034 String Functions](https://img.youtube.com/vi/ey1GaOOnPLI/0.jpg)](https://www.youtube.com/watch?v=ey1GaOOnPLI)

The SQL in the `exercise.sql` file
- Should return the all rows from the `Employee` table with the following columns:
    - The first character of the employee's `FIRST_NAME` renamed to "First Initial"
    - The first character of the employee's `LAST_NAME` renamed to "Last Initial"
    - ONLY the Year from the employee's `DATE` renamed to "Birth Year"
    - The employee's `LOCATION` in all upper case with leading and trailing spaces removed renamed to "Corrected Location"
